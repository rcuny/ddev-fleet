# Guides

Task-oriented pages, in the order you will most likely need them: install Fleet, deploy a first project, then choose how much of the rest you want to automate. Each guide stands on its own, and the reference pages hold the details.

| Page | Read it to |
|---|---|

| [first-project.md](02-first-project.md) | Register a project and open its first site |
| [automate-deploys.md](03-automate-deploys.md) | Deploy per ticket, per branch or nightly, when you want to |
| [run-ci.md](04-run-ci.md) | Give every branch a CI instance |
| [work-with-agents.md](05-work-with-agents.md) | Use the tmux workspace, with or without a coding agent |

| [operate.md](07-operate.md) | Back up, upgrade, move projects, manage capacity |

| [use-the-api.md](09-use-the-api.md) | Create an API token and call Fleet from scripts and CI |

Looking up a flag, a field or a path instead? Go to the [reference](../reference/README.md). New to the vocabulary? Read [concepts](../concepts.md) first.
