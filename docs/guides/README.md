Task-oriented pages, in the order you will most likely need them: install Fleet, deploy a first project, then choose how much of the rest you want to automate. Each guide stands on its own, and the reference pages hold the details.

|---|---|
| [01-install.md](01-install.md) | Install the host: installer, wizard, first sign-in |
| [02-first-project.md](02-first-project.md) | Register a project and open its first site |
| [03-automate-deploys.md](03-automate-deploys.md) | Deploy per ticket, per branch or nightly, when you want to |
| [04-run-ci.md](04-run-ci.md) | Give every branch a CI instance |
| [05-work-with-agents.md](05-work-with-agents.md) | Use the tmux workspace, with or without a coding agent |
