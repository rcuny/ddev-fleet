### Fixed

- The re-auth limiter counts only failed password attempts and is keyed on user and client address, so a hijacked session can no longer lock the real administrator out and successful confirmations never use the budget.
- A sealed export, turning on Git over SSH in the container and deleting a project now close the re-auth window; `docs/secrets.md` notes that an Authelia-only user without a fleet account cannot re-authenticate.
- Playwright: the secret save helper waits for the fresh page instead of submitting a form Turbo was about to replace (flaky 422 on phone).
