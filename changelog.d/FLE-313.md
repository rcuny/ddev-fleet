### Fixed

- Every `ddev start` of an instance timed out on DDEV's web healthcheck since 1.9.0: Mailpit's basic auth (`MP_UI_AUTH`) made the unauthenticated probe on port 8025 answer 401. Fleet now writes `.ddev/web-build/Dockerfile.fleet-mailpit-healthcheck` before every start, which points that probe at Mailpit's unauthenticated `/livez`. The Mailpit UI and API keep their basic auth, and no credential is stored in the image. If a DDEV release changes the script, the build step prints a warning and leaves it alone.
