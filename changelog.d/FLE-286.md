### Added

- API: `POST /api/v1/instances/{id}/terminal` (scope `terminal:write`): types one line of text into an instance's agent pane. Opt-in per project (admin switch behind re-auth, not settable from the CLI, export or import), foreground process must be the agent and is checked again just before the keys are sent, strict text allow-list, 1 call per 2 seconds and 6 per minute, evidence in a new `api_call` table (text included) and an audit entry written before the send (no record, no keys) (FLE-286).

### Changed

- Terminal panes are tagged `tty1` and `tty2` when a window is healed, and read and write find them by that tag, so splitting a pane no longer moves their address. An unterminated OSC payload in a terminal read is cut to the end of its line (FLE-286, from the FLE-285 review).
