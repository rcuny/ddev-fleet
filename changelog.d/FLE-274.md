### Added
- **FLE-274: Caddy route for the HTTP API.** `/api/v1/*` now skips the Authelia login (and only that path; `/api/other` stays gated). The identity strip stays in front of everything, so a forged `Remote-*` / `Remote_*` header never reaches the app. The route is TLS only, caps request bodies at 1 MB, uses a 30-second upstream timeout, sends `Cache-Control: no-store` and no CORS header. A repository test runs the rendered Caddyfile against a real Caddy (`FLEET_CADDY_BIN`) and sends forged identity headers, oversized bodies and path tricks.
