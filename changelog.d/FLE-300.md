### Security

- **FLE-300: instance isolation (audit 2026-11-11, R4 R5 R6 R8).** Every instance gets its own Typesense admin and search keys (derived from the project's keys; a redeploy replaces the old search key). Mailpit requires basic auth with a per-instance password shown on the instance page. The web container mounts the router's `traefik/` cache tree read-only. The installer omits DDEV's shared `ddev-ssh-agent` container. Templates have two new options: *Instances have a database* (off: `FLEET_HAS_DB=0` and a poisoned `DB_HOST`) and *An AI agent works in these instances* (instance page warning, `FLEET_AGENT=1`); both are in the export format, the CLI (`--database`, `--agent`) and the API shapes.

## Rollout

- Redeploy the instances to apply the new Typesense keys, the Mailpit login and the read-only mount (they are baked at deploy).
- Re-run the installer (`ddev push-product`) so the DDEV global config omits `ddev-ssh-agent`; DDEV stops the container at the next `ddev start`.
