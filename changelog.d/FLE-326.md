### Security
- **FLE-326: an instance can no longer reach another instance through `ddev-router` by `Host` header (isolation `enforce` mode).** Fleet writes a Traefik file-provider fragment (`fleet-router-access.yaml` in `~/.ddev/traefik/custom-global-config/`) with a deny router per instance (HTTP, HTTPS and, when the `:443` site mirror is on, a TCP router by SNI) that lets through only the `ddev_default` gateway (Caddy), the loopback, the instance's own containers and the sources of live links. Fleet pushes the file into the router's own Traefik directory (DDEV copies it there only at a `ddev start`) on every isolation pass and removes it there in `report` and `off`; no router restart. The `:443` site mirror forwards only an instance's names for its allowed sources and drops all other connections. `host:isolation:check` verifies the router's copy. See `docs/reference/17-instance-isolation.md`.

## Rollout
- None to apply: the file appears on the next isolation pass of a host in `enforce` mode. Check with an instance's web container: `curl -sk -o /dev/null -w '%{http_code}' -H 'Host: <other instance host>' https://ddev-router/` should no longer return the site.
