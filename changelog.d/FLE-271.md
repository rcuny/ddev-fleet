### Added

- `fleet ssh:check-push-key [--host=bitbucket.org]` and a "Check the push key" button in the SSH keys view test whether the push key itself is registered on a git host. The test ignores the user's `~/.ssh/config` and any ssh-agent (`-F /dev/null`, `IdentitiesOnly`, `IdentityAgent=none`), so a pinned deploy key can no longer make a missing push key look fine. A clear "push key is not registered on the git host" message is shown in the CLI and the UI.
