### Fixed
- **FLE-217: instance ids are shortened so `ddev-<id>-<service>` stays within 63 characters, `-N` suffix included.** DDEV container names longer than a DNS label cannot be resolved by Docker, so the router answered 502 for add-on services (Typesense on a `-1` instance, `typesense-dashboard` always). Derived and fixed labels now keep 20 characters for the service name and room for a `-999` suffix (never cutting a label below 12 characters). Existing ids are unchanged: an over-long existing instance needs a redeploy under a new label. `fleet instance:list` warns about ids too long for `typesense-dashboard`.
