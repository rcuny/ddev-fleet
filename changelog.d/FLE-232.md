### Changed

- Project Keys & secrets tab: the "Git over SSH in the container" setting moved here from the Source tab. It states the risk, asks for a confirmation and writes an audit entry (`project.container-ssh`) when it changes. The tab also lists each template's extra SSH key names (read-only) and links to the host settings for key rotation.
- Secret values are entered in a masked field (a separate textarea for multi-line values) and are never echoed back.
- Turning on Git over SSH in the container needs the server-side confirmation and a recent re-auth, like revealing a secret; turning it off needs neither.
