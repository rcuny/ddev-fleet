### Added
- **FLE-201: capacity S3, the `slices` target of the root helper (epic FLE-197).** `apply slices` installs the systemd slice tree of the CPU allotments: `fleet.slice` (allocatable threads), `fleet-<project>.slice` and `fleet-<project>-<template>.slice` (`-` in a name becomes `_`), as unit files plus `10-fleet-quota.conf` drop-ins. The helper takes data only (`slices.json`, a list of `{unit, quota_percent|null}`), validates every unit name and quota (an integer from 100 to threads x 100), generates the files itself, removes only the slices it wrote earlier, starts every slice before any container and applies each quota to the running slice (`systemctl set-property --runtime`), so a changed limit is live without restarting a container. A failure restores the previous files and quotas. The app syncs the slices after every project or template create, delete and limit change (a failure is a warning); `fleet host:slices [--print]` installs them on demand. Nothing puts a container into a slice yet.

## Rollout
- The new helper and sudoers line arrive with the installer (`ddev push-product`). Afterwards run `fleet host:slices` once to create the slices of the existing projects and templates.
