### Security
- **FLE-298: deploy guard against privileged compose overrides.** A deploy or redeploy is refused, before `ddev start`, when the instance's `.ddev/docker-compose*` or `config*` files mount the Docker socket, run privileged, share a host namespace, add SYS_ADMIN/NET_ADMIN/ALL, pass devices or mount host paths outside the instance. An admin-only, re-authenticated, audited project switch (off by default) allows them. New read-only `instance:audit-overrides`, and `fleet:host:docker-socket [--restore]`; the status watcher checks that the Docker socket is `root:docker` 0660, audits and warns on Settings. See `docs/reference/17-instance-isolation.md`.

## Rollout
- Run `sudo fleet instance:audit-overrides` after the upgrade; redeploy of an instance with a socket mount is refused until the project drops it or an admin allows it.
- If the host socket is not `root:docker` 0660, run `sudo fleet host:docker-socket --restore`.
